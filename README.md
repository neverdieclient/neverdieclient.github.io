# telegup.github.io

Публичный сайт **telegUP** — адрес: <https://telegup.mooo.com>

Здесь лежит только собранный сайт. Исходники — в репозитории
[`neverdieclient/telegUP`](https://github.com/neverdieclient/telegUP), сборка
запускается автоматически каждый час (workflow `Publish telegUP`).

Домен `telegup.mooo.com` привязан через CNAME на `neverdieclient.github.io`.
HTTPS-сертификат GitHub выпускает сам и бесплатно.
